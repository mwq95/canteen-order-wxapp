# 个人中心新功能实现文档

## 一、功能概述

对个人中心页面（profile）进行功能扩展，新增以下四个模块：

| 模块 | 说明 |
|------|------|
| 用户卡片 | 展示微信头像、员工姓名、加密手机号 |

## 三、模块一：用户卡片

### 3.1 数据来源

| 字段 | 来源 | 获取方式 |
|------|------|---------|
| 微信头像 | `app.globalData.userInfo.avatarUrl` | app.js 初始化时获取，或使用默认图 `/images/avatar.png` |
| 员工姓名 | 需新增：通过手机号关联 staffs 查询 | 云函数查询或前端直接查 |
| 手机号 | `app.globalData.phone` | auth.js 验证后存入 globalData |
| 用户角色 | `app.globalData.role` | auth.js 验证后存入 globalData |

### 3.2 手机号加密规则

```
原始号码: 13812345678
显示格式: 138****5678
规则:     前3位 + **** + 后4位
```

### 3.3 员工姓名获取方案

**方案A：在 users 集合中冗余存储姓名（推荐）**

auth.js 的 `createOrUpdateUser` 方法中，验证成功后将员工姓名写入 users 集合：

```javascript
// auth.js - createOrUpdateUser 方法中补充
const userData = {
  phone: staff.phone,
  name: staff.name,        // 新增：员工姓名
  isVerified: true,
  role: staff.role,
  updateTime: new Date()
};
```

同时在 app.js 的 `checkUserStatus` 中读取：

```javascript
// app.js - checkUserStatus 补充
this.globalData.name = user.name || null;  // 新增
```

**方案B：profile 页面加载时查询 staffs 集合**

```javascript
// profile.js
loadStaffName() {
  const phone = app.globalData.phone;
  if (!phone) return;
  
  const db = wx.cloud.database();
  db.collection('staffs').where({ phone }).get().then(res => {
    if (res.data.length > 0) {
      this.setData({ staffName: res.data[0].name });
    }
  });
}
```

> **推荐采用方案A**，减少数据库请求次数。

#### JS

```javascript
const app = getApp();

Page({
  data: {
    orderReminder: true,
    mealReminder: true
  },

  onLoad() {
    this.loadSettings();
  },

  loadSettings() {
    const db = wx.cloud.database();
    db.collection('users').where({
      _openid: app.globalData.openid
    }).get().then(res => {
      if (res.data.length > 0) {
        const user = res.data[0];
        this.setData({
          orderReminder: user.subscribeOrderReminder !== false,
          mealReminder: user.subscribeMealReminder !== false
        });
      }
    });
  },

  onOrderReminderChange(e) {
    const value = e.detail.value;
    if (value) {
      this.requestSubscribeAndSave('order');
    } else {
      this.saveSetting({ subscribeOrderReminder: false });
    }
    this.setData({ orderReminder: value });
  },

  onMealReminderChange(e) {
    const value = e.detail.value;
    if (value) {
      this.requestSubscribeAndSave('meal');
    } else {
      this.saveSetting({ subscribeMealReminder: false });
    }
    this.setData({ mealReminder: value });
  },

  requestSubscribeAndSave(type) {
    const templateId = wx.getStorageSync('subscribeTemplateId') || '';
    
    if (!templateId) {
      wx.showToast({ title: '模板ID未配置', icon: 'none' });
      return;
    }

    wx.requestSubscribeMessage({
      tmplIds: [templateId],
      success: (res) => {
        if (res[templateId] === 'accept') {
          if (type === 'order') {
            this.saveSetting({ subscribeOrderReminder: true });
          } else {
            this.saveSetting({ subscribeMealReminder: true });
          }
          wx.showToast({ title: '已开启', icon: 'success' });
        } else {
          if (type === 'order') {
            this.setData({ orderReminder: false });
          } else {
            this.setData({ mealReminder: false });
          }
          wx.showToast({ title: '已拒绝', icon: 'none' });
        }
      },
      fail: () => {
        if (type === 'order') {
          this.setData({ orderReminder: false });
        } else {
          this.setData({ mealReminder: false });
        }
      }
    });
  },

  saveSetting(data) {
    const db = wx.cloud.database();
    db.collection('users').where({
      _openid: app.globalData.openid
    }).update({
      data: {
        ...data,
        updateTime: new Date()
      }
    });
  }
});
```

### 4.4 与订餐流程的联动

在 `order.js` 的 `doSubmitOrder` 方法中，判断是否发送提醒：

```javascript
// order.js - doSubmitOrder 中修改
if (hasSubscribed && !existingOrder.orderId) {
  // 检查用户的订餐提醒设置
  this.checkAndSendReminder(mealType, selections);
}

checkAndSendReminder(mealType, selections) {
  const db = wx.cloud.database();
  db.collection('users').where({
    _openid: app.globalData.openid
  }).field({ subscribeOrderReminder: true }).get().then(res => {
    if (res.data.length > 0 && res.data[0].subscribeOrderReminder !== false) {
      this.sendSubscribeMessage(mealType, selections);
    }
  });
}
```

## 五、模块三：订餐统计

### 5.1 功能说明

展示用户的订餐数据统计，分为四个维度：
- **本周**：当前自然周的订餐数据
- **本月**：当前月份的订餐数据
- **本年**：当前年份的订餐数据
- **总计**：所有时间的累计数据

每个维度显示三个指标：
- **总订单数**：该时间段内所有订单
- **已完成**：状态为 completed 或 pending 且超过开饭时间
- **已取消**：状态为 cancelled

#### JS

```javascript
const app = getApp();

Page({
  data: {
    weekRange: '',
    monthRange: '',
    yearRange: '',
    weekData: { total: 0, completed: 0, cancelled: 0 },
    monthData: { total: 0, completed: 0, cancelled: 0 },
    yearData: { total: 0, completed: 0, cancelled: 0 },
    totalData: { total: 0, completed: 0, cancelled: 0 }
  },

  onLoad() {
    this.setDateRanges();
    this.loadAllStats();
  },

  setDateRanges() {
    const now = new Date();
    
    // 本周范围
    const dayOfWeek = now.getDay() || 7;
    const monday = new Date(now);
    monday.setDate(now.getDate() - dayOfWeek + 1);
    const sunday = new Date(monday);
    sunday.setDate(monday.getDate() + 6);
    this.setData({
      weekRange: `${this.formatDate(monday)} ~ ${this.formatDate(sunday)}`
    });

    // 本月范围
    const firstDay = new Date(now.getFullYear(), now.getMonth(), 1);
    const lastDay = new Date(now.getFullYear(), now.getMonth() + 1, 0);
    this.setData({
      monthRange: `${now.getFullYear()}年${now.getMonth() + 1}月`
    });

    // 本年
    this.setData({
      yearRange: `${now.getFullYear()}年`
    });
  },

  formatDate(date) {
    const m = date.getMonth() + 1;
    const d = date.getDate();
    return `${m}/${d}`;
  },

  async loadAllStats() {
    await Promise.all([
      this.loadWeekStats(),
      this.loadMonthStats(),
      this.loadYearStats(),
      this.loadTotalStats()
    ]);
  },

  getWeekStartEnd() {
    const now = new Date();
    const dayOfWeek = now.getDay() || 7;
    const start = new Date(now);
    start.setDate(now.getDate() - dayOfWeek + 1);
    start.setHours(0, 0, 0, 0);
    const end = new Date(start);
    end.setDate(start.getDate() + 6);
    end.setHours(23, 59, 59, 999);
    return { start, end };
  },

  getMonthStartEnd() {
    const now = new Date();
    const start = new Date(now.getFullYear(), now.getMonth(), 1);
    const end = new Date(now.getFullYear(), now.getMonth() + 1, 0, 23, 59, 59, 999);
    return { start, end };
  },

  getYearStartEnd() {
    const now = new Date();
    const start = new Date(now.getFullYear(), 0, 1);
    const end = new Date(now.getFullYear(), 11, 31, 23, 59, 59, 999);
    return { start, end };
  },

  async loadWeekStats() {
    const { start, end } = this.getWeekStartEnd();
    const stats = await this.queryStats(start, end);
    this.setData({ weekData: stats });
  },

  async loadMonthStats() {
    const { start, end } = this.getMonthStartEnd();
    const stats = await this.queryStats(start, end);
    this.setData({ monthData: stats });
  },

  async loadYearStats() {
    const { start, end } = this.getYearStartEnd();
    const stats = await this.queryStats(start, end);
    this.setData({ yearData: stats });
  },

  async loadTotalStats() {
    const stats = await this.queryStats(null, null);
    this.setData({ totalData: stats });
  },

  queryStats(startTime, endTime) {
    const db = wx.cloud.database();
    let query = db.collection('orders').where({
      _openid: app.globalData.openid
    });

    if (startTime && endTime) {
      query = query.where({
        _openid: app.globalData.openid,
        createTime: db.command.gte(startTime).and(db.command.lte(endTime))
      });
    }

    return query.count().then(countRes => {
      return db.collection('orders')
        .where(query._query._query)
        .count()
        .then(() => {
          // 分批查询以获取详细状态
          return this.queryDetailedStats(startTime, endTime);
        });
    });
  },

  async queryDetailedStats(startTime, endTime) {
    const db = wx.cloud.database();
    let whereCondition = { _openid: app.globalData.openid };

    if (startTime && endTime) {
      whereCondition.createTime = db.command.gte(startTime).and(db.command.lte(endTime));
    }

    // 总订单数
    const totalRes = await db.collection('orders')
      .where(whereCondition)
      .count();

    // 已取消数量
    const cancelledRes = await db.collection('orders')
      .where({
        ...whereCondition,
        status: 'cancelled'
      })
      .count();

    // 已完成数量（status=completed 或 pending但已过开饭时间）
    const allOrders = await db.collection('orders')
      .where(whereCondition)
      .orderBy('createTime', 'desc')
      .limit(1000)
      .get();

    let completedCount = 0;
    for (const order of allOrders.data) {
      if (order.status === 'completed') {
        completedCount++;
      } else if (order.status === 'pending') {
        // 检查是否已过开饭时间
        const deadlines = this.getDeadlinesFromCache(order.mealType);
        const mealEndTime = this.getMealEndTime(order.mealType, deadlines);
        const orderDate = new Date(order.date);
        const [eh, em] = mealEndTime.split(':').map(Number);
        const mealEndDateTime = new Date(orderDate);
        mealEndDateTime.setHours(eh, em, 0, 0);

        if (new Date() > mealEndDateTime) {
          completedCount++;
        }
      }
    }

    return {
      total: totalRes.total,
      completed: completedCount,
      cancelled: cancelledRes.total
    };
  },

  getMealEndTime(mealType, deadlines) {
    const map = {
      '早餐': deadlines?.breakfastMealStart || '08:00',
      '午餐': deadlines?.lunchMealStart || '12:00',
      '晚餐': deadlines?.dinnerMealStart || '17:30'
    };
    return map[mealType] || '12:00';
  },

  getDeadlinesFromCache() {
    // 从缓存或全局数据获取截止时间配置
    try {
      const cached = wx.getStorageSync('deadlineConfig');
      if (cached) return JSON.parse(cached);
    } catch (e) {}
    return null;
  }
});
```

### 5.3 性能优化建议

由于统计查询可能涉及大量数据，建议：
1. **云函数聚合查询**：将统计逻辑放在云端执行，避免传输大量数据
2. **缓存机制**：统计数据缓存 5 分钟，避免频繁查询
3. **分页处理**：如果订单量很大，分批次查询

可选优化方案：新增云函数方法 `getOrderStats`

```javascript
// cloudfunctions/quickstartFunctions/index.js 新增
const getOrderStats = async (event, openid) => {
  const { period } = event; // 'week' | 'month' | 'year' | 'total'
  const now = new Date();
  let startTime, endTime;

  switch (period) {
    case 'week':
      const dayOfWeek = now.getDay() || 7;
      startTime = new Date(now); startTime.setDate(now.getDate() - dayOfWeek + 1);
      endTime = new Date(startTime); endTime.setDate(startTime.getDate() + 6);
      break;
    case 'month':
      startTime = new Date(now.getFullYear(), now.getMonth(), 1);
      endTime = new Date(now.getFullYear(), now.getMonth() + 1, 0);
      break;
    case 'year':
      startTime = new Date(now.getFullYear(), 0, 1);
      endTime = new Date(now.getFullYear(), 11, 31);
      break;
    default:
      startTime = null;
      endTime = null;
  }

  let query = db.collection('orders').where({ _openid: openid });
  if (startTime && endTime) {
    query = query.where({
      _openid: openid,
      createTime: db.command.gte(startTime).lte(endTime)
    });
  }

  const [totalRes, cancelledRes, allOrders] = await Promise.all([
    query.count(),
    db.collection('orders').where({ ...query._query._query, status: 'cancelled' }).count(),
    query.limit(1000).get()
  ]);

  let completedCount = 0;
  for (const order of allOrders.data) {
    if (order.status === 'completed') completedCount++;
  }

  return {
    success: true,
    data: {
      total: totalRes.total,
      completed: completedCount,
      cancelled: cancelledRes.total
    }
  };
};
```
